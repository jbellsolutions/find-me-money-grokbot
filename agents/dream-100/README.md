# Dream 100

The 100 partners where one yes changes the business. One researched dossier and one hand-written first touch each, by email and on socials, then patient follow-up.

| | |
|---|---|
| Engine | grokbot |
| Tier | 1 |
| Channels | email, linkedin, x, instagram, youtube |
| Message types | dream100_first_touch, dream100_follow_up |

## What it is built from today

In the `revenue-os-max` kit (the product's base, in the same factory):

- Roles: `roles/dream.md`, `roles/partners.md`
- Skills: `dream-partner-portfolio`, `partner-opportunity-research`, `high-level-prospecting`
- Worker jobs: none

## Files here

| File | What |
|---|---|
| [PROCESS.md](PROCESS.md) | What the owner said, the twelve steps, the channels, the first touch, and the rules, all of them his |

| [prompts/score.md](prompts/score.md) | Scoring a candidate, with evidence and a link for each item |
| [prompts/dossier.md](prompts/dossier.md) | The dossier fields |

| [prompts/follow-up.md](prompts/follow-up.md) | A follow-up that brings something new |
| [dream100.py](dream100.py) | Checks a settings file is filled in and adds up a score. Finds nobody, sends nothing |
| [STATUS.md](STATUS.md) | The keep-or-remove list, where the function stands, and what the owner still needs to say |
