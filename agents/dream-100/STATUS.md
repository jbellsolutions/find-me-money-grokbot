## Where the function stands

Written: the process, a settings example, four prompts, and a script that checks a settings file and adds up a score. Not built: no finder, no list for any business, no routine installed, nothing sent. `dream100.py` was run on the example settings, a score, and a settings file with an empty ask and an email address in it; each gave the expected answer.
