# First touch, DM

Message type `dream500_first_touch`, channel `linkedin`, `x`, `instagram` or `community`. Same fields as the email, shorter because it is a DM. The wording is a first draft for the owner to change.

```
Hi {first_name}, I've been following {group_name}. {{what_we_do}} Here's a recent episode: {{episode_url}} Who's the right person to ask about an affiliate partnership or a giveaway for your group? Also glad to send your people something useful on {topic}. {{signs_as}}
```
